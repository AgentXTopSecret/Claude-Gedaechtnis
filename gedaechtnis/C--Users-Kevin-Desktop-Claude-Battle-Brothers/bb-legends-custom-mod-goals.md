Kevin (German speaker, answer in German) plays Battle Brothers with the Legends mod and wants a custom submod (started 2026-10-24).

Requirements stated by the user:
- Always use the NEWEST Legends version (official GitHub Battle-Brothers-Legends/Legends-public releases; Nexus mod 60).
- German translation Nexus mod 1085 (mod_aaa_neu_de_base.zip + mod_zz_neu_de_legends.zip) — it replaces Legends .nut files with translated copies, so the custom mod must use hooks, not file overrides.
- More recruitable bros per town, recruits with high stats ("nicht so random").
- Every background available in every town, all backgrounds EQUALLY rare and all findable — "kein random shit".
- Every bro gets (nearly) all perks to learn, including perks from other perk mods, EXCEPT magic/special class trees (e.g. Vala "Warden" sorcerer perks) which stay only on their special backgrounds.
- The magic exclusion applies ONLY to perks, not to recruiting: Vala and other mage classes should be recruitable in towns (MSU setting, default on, each class safety-checked), at a normal hiring price instead of Legends' (Vala 20,000); daily wage stays as in Legends (decided 2026-10-26 after Claude had wrongly excluded them from the recruit pool).
- All perk mods that work together with Legends should be included.
- User starts a completely NEW campaign with this setup — no need to migrate old savegames or existing bros.

**Why:** user wants a deterministic, non-random campaign where any build is possible with any bro.
**How to apply:** keep these rules when changing the mod or the mod list; game install is Steam on C: (game 1.5.2.3); a stale copy lives on D:\SteamLibrary (not registered in Steam).
